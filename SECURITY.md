# Security Policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/ichenh/obsidian-typesetter/security/advisories/new). Do not include sensitive details in a public issue.

Include the affected version, Obsidian version, reproduction steps, impact, and a minimal sample note when safe. You should receive an acknowledgement within seven days. No bounty program is currently offered.

Typography mistakes without a security impact may be reported through the public issue tracker.
